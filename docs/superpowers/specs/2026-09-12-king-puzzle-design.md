# king-puzzle 設計（2026-09-12）

ターン制の城攻めパズル。ソロ専用。**完全に決定的な完全情報ゲーム。**

**§7 が engine の唯一の真実である。** ここが1ステップ違うと全ステージの `T*` が変わり、
★の基準も難易度の測定値もすべて無効になる。

測定結果は §21 に置く。本書の数値は使い捨てスクリプトで実装・全探索して検証したものだが、
**§7 のターン構造を交互制に改めたので、該当する数値は実装後に測り直す**（§21 末尾）。

---

## 1. これは何のゲームか

盤面には最初から施設が置いてある。小屋で駒を買い、訓練場で育て、採掘場で稼ぎ、
育った駒が壁を壊し、**相手の王を倒したら勝ち**。

自分の王を失ったら負け。途中に壁があり、敵は決まったリズムで攻撃してくる。

**敵は思考しない。** 敵の行動は盤面と手番から一意に決まる。
乱数も隠し情報もないので、

- 盤面を見れば最適解が存在する
- ソルバーで最少ターン `T*` を求められる
- **難易度を、人の匙加減なしに数値で測れる**（§9）

この決定性が設計全体の土台である。**思考する CPU は入れない**（§18）。

## 2. 中核となる5つのルール

### ① 1つのノードに、駒は1つしか置けない

溜まらない。だから駒は**自分の道を塞ぐ**し、施設は**1つの駒しか使えない**。

### ② 1ターンに1つだけ行動する

操作の文法は1つしかない。**何かを選ぶ → 行き先を選ぶ。**
隣を選べば移動、いまの場所を選べば足踏み。

**「何もしない」という専用のボタンは無い。** 足踏みがその役割を兼ねる。
ただし足踏みは**どの駒をその場に留めるか**を選ぶ行為なので、位置が結果に残る。

### ③ 施設は、自分のターン終了時にそこに居る駒に効く。効果の上限は施設のレベル

通過して一瞬で効くのではない。**そこに居たまま、自分のターンを終える。**

| 施設 Lv N の上で自分のターンを終えたとき | 効果 | 上限 |
|---|---|---|
| **訓練場** | 駒のレベル +1 | 駒が Lv N になるまで |
| **採掘場** | コインを獲得（N に比例） | なし |
| **馬小屋** | 駒の移動速度 +1 | 速度が N になるまで |

**発動するのは、そのターンのプレイヤーの駒だけ**（§7）。
自分の駒は自分のターンの終わりに、敵の駒は敵のターンの終わりに効果を受ける。

**足止めされた駒は効果を受けない**（§2④）。

上限があるので、同じ施設を往復して無限に強くすることはできない。
1ノード1駒なので、**訓練場は一度に1体しか育てられない。** 渋滞が本物のコストになる。

### ④ 施設のレベルを上げられるのは、そこに居る駒が足踏みしたときだけ

駒を選んで、行き先に**いまの場所そのもの**を選ぶ＝足踏み。
**足踏みすると、その施設のレベルが1上がる**（コインを払う）。確認は出さない。

**駒が居ない施設のレベルは上げられない。**

**選べる駒であれば、足踏みはいつでも選べる。効果が無ければ何も起きない。**

| 足踏みしたとき | 起きること |
|---|---|
| 施設の上、コインが足り、上限未満 | 施設が Lv+1。コインを払う |
| 小屋の上 | 何も起きない（小屋はレベルを持たない） |
| 施設が最大レベル | 何も起きない |
| コインが足りない | 何も起きない |
| 道・自城・壊れた壁の上 | 何も起きない |

**足止めされた駒は、そもそも選べない。** 移動も足踏みもできず、
**その駒が居る施設の効果も受けない**（訓練場で育たず、採掘場で稼がない）。

したがって、**選べる駒（足止めされていない自分の駒）が1つでもあれば合法手は存在する。**

### 何もできないとき ―― 強制スキップ

選べる駒が1つも無く、生成もできないときは、**特殊な演出とともに1ラウンド強制スキップする。**
敗北にはしない。足止めは「何ラウンドか動けない」罰であって、死ぬ罰ではないため。

ソルバーは「合法手が強制スキップ1つだけの局面」として扱う。決定性も許容度の計算も成立する。
**強制スキップが最適解の周辺に現れる盤面は監査で落とす**（§17）。

### ⑤ 王を失ったら、その場で負け。相手の王を倒したら勝ち

自分にも相手にも king 駒がある。開始時、自分の king は自城に、相手の king は敵城に置かれる。
king は普通の駒として動き、施設の効果も普通に受ける。

**勝敗は king の生死だけで決まる。** 敵城という特別なノードは無く、
「敵城」は**相手の king の初期位置**を指す呼び名である。

**king は普通の駒として自由に動く。** 採掘場で稼ぎ、訓練場で育ち、道を進み、敵陣へも行ける。
ただし取られたら負けるので、**動かすたびにリスク判断が発生する。**

測定では **74% の面で king を自城に固定すると `T*` が悪化し**（うち 41% は解けなくなる）、
**79% の面で最後の一撃を入れたのは king 自身**だった。

**この割合は成り行きに任せる。どちらの方向にも調整しない。**

序盤の面は相手の駒が無く、敵の攻撃を避けるだけなので、**王が自ら先陣を切るのは理にかなっている。**
駒が増える後半の面では、育てた駒が突っ込み king は下がる形に自然と寄る。
**その推移をルールや監査で強制しない。**

## 3. 盤面

ノードとエッジのグラフ。グリッドではない。
**エッジは隣接関係だけを表し、長さを持たない。** 距離はホップ数で数える。

```
  (自城)──[小屋]──(道)──[訓練場 Lv2]
     │                       │
  [採掘場]──(道)──[壁 Lv3]──(道)──[訓練場 Lv4]──(道)──(敵城)
     ▲                                              ▲
   自 king                                        敵 king Lv4
```

| ノード | 役割 |
|---|---|
| **自城** | 自分の king の初期位置。それ以外は道と同じ |
| **敵城** | 相手の king の初期位置。それ以外は道と同じ |
| **施設** | 小屋・採掘場・訓練場・馬小屋。最初から置いてある。初期レベルも作問で決める |
| **壁** | レベルを持つ。それ以上の駒が移動すると壊れ、**その駒は消える** |
| **道** | 何もない通過専用ノード |

**施設を「建てる」という行動は存在しない。** どこに何を置くかは作問側が決める。
ゲームは「建設順パズル」ではなく**「運用パズル」**である。

壊れた壁ノードは、以後**道と同じ**に扱う。

### 施設は敵陣にもある。小屋を除いて、誰の施設でもない

**盤面の全域に施設を配置してよい。壁の向こう、敵城のそばにも置く。**
**採掘場・訓練場・馬小屋に所有者はいない。そこに居る駒が誰であっても効果を受ける。**

- こちらの駒が敵陣の訓練場に入れば、レベルが上がる
- 敵の駒がこちらの馬小屋に入れば、その敵駒が馬を手に入れる

「自陣」「敵陣」はルール上の区別を持たない。**呼び名と作問上のラベルだけ**である。

### 小屋だけは所有者を持つ

**小屋には所有者があり、そのプレイヤーしか駒を生成できない。**
自分の駒が相手の小屋に入っても生成はできない。

ただし**塞ぐことはできる**。1ノード1駒なので、
**相手の小屋に自分の駒を置けば、相手の駒の生成を止められる。** 逆もまた然り。

所有者を持つのは小屋だけなので、対称性は崩れない（お互いに自分の小屋を持つ）。

**敵陣の訓練場を自陣より高レベルに置けば**、
「壁を壊してでも育てに行くか、手前の弱い訓練場で妥協するか」という二択になる。

**ただし成立条件がある**（測定値、§21）。

> **相手の king が Lv3 以上、かつ敵陣の訓練場が Lv3 以上**でなければ、奥の施設は一度も使われない。

妥協したときの損は +1〜+3 ターンなので、**制限に +2 以上の余裕があれば本当の二択になる。**

効いている理由はレベル差だけではない。**壁を壊す駒と王に届く駒が1つの訓練場を奪い合う渋滞**を、
奥の訓練場がほどいている。§2① が §3 を支えている。

- 1ステージのノード数は **7〜13**

## 4. 資源はコインだけ

数える資源はコイン1種のみ。画面に出る数字は**コインとターンの2つだけ**。
使い道は2つ。**駒を生成する**（小屋で）と、**施設のレベルを上げる**（足踏みで）。

## 5. 駒・移動・戦闘

### 駒

| 属性 | 意味 | 初期値 |
|---|---|---|
| `level` | 駒の力。1以上 | 1 |
| `king` | 王かどうか。各陣営に1つ。失うと負け | — |
| `speed` | 1アクションで進むホップ数 | 1 |
| `snared` | 残り何ターン行動できないか | 0 |

### 移動できない条件

1. 移動先に**自分の駒**が居る
2. 移動先が未破壊の壁で、**駒のレベルが壁のレベルに満たない**
3. **移動先が未破壊の壁で、動かそうとしているのが自分の king**
4. **移動先の敵駒のレベルが自分以上**で、動かそうとしているのが自分の king
5. その駒が足止めされている（`snared > 0`）
6. 移動先が封鎖されている

3 と 4 は**自滅操作を作らない**という同じ方針から来ている。
壁を壊すと駒は消え、同レベル以上の敵駒に突っ込めば king は死ぬ。どちらも即敗北なので選べないようにする。

**逆に言えば、king は自分より弱い敵駒にはぶつけられる。** 相手の king も同じで、
**自分の king のレベルが相手の king を上回っていれば、king 自身で決着をつけられる。**

### 戦闘

移動先に**敵の駒**が居るときは、移動して戦闘になる。

> **レベルの高いほうが勝ち、敗者は消える。勝者は敗者のレベルぶんレベルが下がり、そのノードへ進む。**
> **同レベルなら相打ちで両方消え、そのノードは空になる。**

```
Lv3 の自駒 → Lv2 の敵駒が居るノードへ移動
  → 敵駒が消える。自駒は Lv3 − 2 = Lv1 になってそのノードへ進む

Lv3 の自駒 → Lv3 の敵駒
  → 相打ち。両方消える
```

**1体の超強力な駒で受け続けることができない**のがこの規則の要点である。

### 勝ち方は2通りある

相手の king も**普通の駒である**。だから倒し方も普通の駒と同じ2通りがある。

**① 一撃で倒す**

相手の king と**同レベル以上の駒**をぶつける。同レベルなら相打ちで、相手の king が消えて勝ち。
自分の king は無事なので、`相手の king のレベル` ちょうどの駒が1体あれば足りる。

**② 削ってから倒す**

勝者は敗者のレベルぶん下がるので、**負ける戦闘にも意味がある。**

```
相手の king Lv5 に、Lv2 の駒をぶつける
  → 自駒は消えるが、相手の king は Lv5 − 2 = Lv3 になる
Lv2 の駒をもう1体ぶつける
  → 相手の king は Lv3 − 2 = Lv1 になる
Lv2 の駒を3体目
  → 2 > 1 で勝ち。相手の king が消えて勝利
```

**育てて1体で仕留めるか、安い駒を並べて削るか**という選択が生まれる。

どちらが得かは**盤面の形が決める**。敵陣が遠ければ駒を何体も運ぶコストが重く、育成型が有利。
近ければ消耗型が有利。訓練場が高レベルなら育成型、小屋が近くコインが余るなら消耗型。

**この選択は作問の主要なつまみの1つである**（§11）。

### 壁は無意味な自滅を禁じ、戦闘は許す ―― 一貫している

壁はレベル不足だと移動できない（§5 の条件2）が、戦闘は負ける相手にも突っ込める。
一見ちぐはぐだが、理由がある。

- **壁でレベルが足りない移動は、何も起きずに駒だけ消える。完全な無駄**なので禁じる
- **戦闘で負ける移動は、相手のレベルを削る。有効な手**なので許す

king だけは戦闘でも禁じる（条件4）。**負ければ即敗北で、削る価値より損が大きいため。**

## 6. 施設

| 施設 | 効果 |
|---|---|
| **小屋** | **レベルを持たない。** ノードが空のとき、コインを払って Lv1 の駒を生む |
| **採掘場** Lv N | 駒が在るあいだ毎ターン `2×N` コイン |
| **訓練場** Lv N | 駒が在るあいだ毎ターン駒の Lv+1。駒が Lv N になったら止まる |
| **馬小屋** Lv N | 駒が在るあいだ毎ターン速度 +1。速度が N になったら止まる |

費用のたたき台。**engine の定数として1箇所に置く**（`src/engine/costs.ts`）。

| | Lv2 へ | Lv3 へ | Lv4 へ | Lv5 へ |
|---|---|---|---|---|
| 採掘場 | 4 | 5 | 7 | 9 |
| 訓練場 | 5 | 6 | 8 | 10 |
| 馬小屋 | 6 | 8 | — | — |

駒の生成費は 2。施設レベルの上限は 5。コインの上限は 30。

### 小屋がレベルを持たない理由

**持たせると訓練場と役割が重なり、訓練場が死ぬ。** 測定で確認した（§21）。
小屋 Lv N が Lv N の駒を生む設計だと、小屋を上げるほうが安いため、
最適解が「小屋だけ使って終わり」になった。

小屋は**量**（コインを駒に換える）、訓練場は**質**（駒のレベルを上げる）。

### 足踏みは強制レベルアップでよい

確認を出すと操作が2段になる。出さない。
強制にしても `T*` は**1ターンも変わらなかった**（13.1 → 13.1、§21）。

## 7. ターンの進み方 ―― engine の唯一の真実

**自分のターンと相手のターンが交互に来る。** 1組を**1ラウンド**と数える。
`T*` は**自分が行動した回数**（＝ラウンド数）である。

```
═══ ラウンド t ═══════════════════════════

【自分のターン】

 1. 行動を1つ選ぶ
      移動 … 駒を隣のノードへ
             ├ 移動先に敵の king が居て、戦闘に勝つ／相打ちになる
             │    → 【勝利。ここで終了】
             ├ 移動先が未破壊の壁でレベル条件を満たす
             │    → 壁が壊れ、その駒は消える（ノードは空になる）
             ├ 移動先に敵駒 → 戦闘（§5）
             └ それ以外 → 駒がそのノードへ移る
      足踏み … その駒が居る施設のレベルを +1。コインを即座に払う
              （条件を満たさないときは何も起きない。§2④）
      生成   … 自分の空の小屋に Lv1 の駒を置く。コインを即座に払う

      ※ 選べる駒（足止めされていない自分の駒）が1つも無く、生成もできないときは
        **強制スキップ**。何もせず 2 へ進む。ソルバーはこれを合法手1つの局面として扱う（§2④）

 2. ターン終わりの施設発動
      **自分の駒のうち、足止めされていないもの**が居る施設だけが発動する
        訓練場: 駒の Lv < 施設 Lv なら Lv+1
        採掘場: コイン += 2 × 施設 Lv
        馬小屋: 駒の速度 < 施設 Lv なら 速度+1
      ※ 1 の足踏みで上げたレベルは、この 2 に反映される
      ※ 逆に、1 の支払いに 2 の収入は使えない

【相手のターン】

 3. 攻撃のカウントを1減らす
      0 になった攻撃が発火し、効果を適用したのちカウントを `period` に戻す
      **攻撃が当たるのはプレイヤーの駒だけ。** 対象ノードに敵駒が居ても何も起きない

 4. 敵の駒の生成と移動（§8）

 5. ターン終わりの施設発動
      **敵の駒のうち、足止めされていないもの**が居る施設だけが発動する

 6. 持続効果の減算
      すべての駒の `snared`、すべてのノードの封鎖残ターンを 1 減らす
      ただしこのラウンドの 3 で付与されたものは減らさない
      → `duration: N` なら、ちょうど N ラウンド行動できない／通れない

 7. 敗北判定
      自分の king が盤上に居ない → 敗北

 8. t を +1。t > `T* + S` なら時間切れで敗北

═══ ラウンド t+1 へ ═══════════════════════
```

### 攻撃のカウント

各攻撃は**残りカウント**を持ち、**相手のターンの開始時に1減る。0 になったら発火**する。
発火後は `period` に戻る。

初期カウントは `initial`（省略時は `period`）。これで発火のずれを表す。

```ts
{ type:'arrow',  target:'mine',     period:4 }              // T4, T8, T12…
{ type:'cannon', target:'training', period:4, initial:5 }   // T5, T9, T13…
{ type:'snare',  target:'road2',    period:3, duration:2 }  // T3, T6, T9…
```

**画面に出る「あと N ターン」は、このカウントそのものである。**

### 判定の優先順位

**勝利 > 敗北 > 時間切れ。** 勝利は自分のターンで即座に確定し、以降を実行しない。

### 行動できる回数

プレイヤーは **`T* + S` 回**行動できる。`T* + S` 回目で勝てばクリア（★1）。

### 操作

| 選ぶもの | 行き先 | 行動 |
|---|---|---|
| 自分の駒 | 隣のノード | **移動**（敵駒が居れば戦闘） |
| 自分の駒 | いまの場所 | **足踏み**（条件を満たせばレベルアップ、満たさなければ何も起きない） |
| **空の小屋** | いまの場所 | **生成** |

例外は「選べる対象に**空の小屋**が入る」ことだけで、ジェスチャは1種類のまま。

## 8. 敵の行動

**敵は思考しない。行動は盤面と手番から一意に決まり、すべて事前に画面へ出す。**

### 定期攻撃

`{ 種類, 対象, 周期, 初期カウント, 持続 }` の**配列**を持つ。数も中身もステージごとに自由。

| 種類 | 効果 | 持続 |
|---|---|---|
| **弓** | 対象ノードの駒を **Lv−1**。Lv1 だった駒は消える | — |
| **大砲** | 対象ノードの駒を**レベルに関わらず消す** | — |
| **足止め** | 対象ノードの駒を `duration` ラウンド行動不能にする | **1〜2** |
| **封鎖** | 対象ノードを `duration` ラウンド**進入禁止**にする。駒が居なくても効く | **1〜2** |

**封鎖されたノードには入れない。既にそこに居る駒は出られる。** 施設効果は発動し、足踏みもできる。
閉じ込めを作らないための裁定である。

**攻撃が当たるのはプレイヤーの駒だけである。** 対象ノードに敵駒が居ても何も起きない。
敵が自分の駒を撃つことはない。

複数の攻撃が同じラウンドに発火するときは、**対象を先に全部決めてから、配列順に適用する。**

**測定値（§21）**: 足止め・封鎖は弓・大砲より**明確に弱い**。`T*` も解ける率もほとんど動かない。
**主役ではなく、リズムの味付けとして使う。** 状態空間は1.3倍で実用上の影響はない。
**`duration: 3` は使わない** ―― 封鎖 N=3 で解ける面が 20/24 → 16/24 に落ち、手詰まりが 7.8 倍になった。

### 追尾攻撃

周期は固定のまま、**撃つ相手を盤面から決める**。規則は画面に明示する。

| 規則 | 狙う相手 | 同率のときの決め方 |
|---|---|---|
| `nearest-to-enemy` | 相手の king にいちばん近い自駒 | ノードIDの昇順で先のもの |
| `highest-level` | いちばんレベルの高い自駒 | 同上 |
| `king` | 自分の king | 一意 |

距離は**現在の盤面での**ホップ数で測る（未破壊の壁は通れない辺として扱う）。
狙える駒が1つも無いラウンドは、その攻撃は何もしない。

**推奨設定（測定で決定、§21）**

```ts
{ type:'snare', duration:2, rule:'king', period:4 }
```

| | 解ける | 同時駒数 | 生成体数 |
|---|---|---|---|
| 定期攻撃（基準） | 10/16 | 2.30 | 1.40 |
| **king を足止め** | **12/16** | **3.00** | **2.08（+49%）** |

**解ける率を落とさずに駒を5割増やせる、唯一の設定である。**
king が動けない間は、他の駒を動かすか無駄な足踏みをするしかない。だから駒を先に用意する必要が出る。
king を殺さないので詰まない。

**禁止する組み合わせ**

| 組み合わせ | 理由 |
|---|---|
| `rule:'king'` × 大砲 | **0/16。** 即敗北になる |
| `rule:'king'` × 弓 | 5〜8/16。基準を下回る |
| `nearest-to-enemy` × 弓 × 周期3 | **5/16。** 先頭を必ず潰されて突撃が全部死ぬ |

### 敵の駒

**敵の小屋が**周期ごとに敵駒を生み、盤上を動く。
**敵駒も施設の効果を受ける**（§3・§7 のステップ5）。

生成の規則はこちらと同じである。**敵の小屋が空いているときだけ生成される**ので、
**こちらの駒で敵の小屋を塞げば、敵の生産を止められる。**

| 段階 | 敵駒の動き | 敗北条件 |
|---|---|---|
| **占拠型** | `target` の施設まで進み、そこに居座る | 増えない |
| **進軍型** | 自分の king へ最短経路で進む | 戦闘で自分の king が負ければ敗北 |

**進軍型の経路の決め方**（決定性のために必ず守る）

1. 目標は**自分の king の現在地**。毎ラウンド再計算する
2. 未破壊の壁と封鎖ノードは通れない辺として扱う
3. 最短経路が複数あるときは、**次に進むノードのIDが昇順で先のもの**
4. 次のノードが自駒で埋まっていれば戦闘を仕掛ける（§5）
5. 次のノードが別の敵駒で埋まっていればその場に留まる
6. 敵の小屋が塞がっているラウンドは、生成をスキップする

**敵駒とコイン・足踏み**: 敵駒は足踏みをしない（コインを持たないため）。
敵駒が採掘場に居てもコインは誰にも入らない。訓練場・馬小屋の効果は受ける。
**占拠型を訓練場に置くと敵駒は訓練場レベルまで育つ**ので、作問時に織り込む。

### 相手の king

相手の king は**盤上の駒**である。**当面はすべての面で動かさない**（敵城に置いたまま）。
城には施設が無いので、相手の king が施設の効果で育つことはない。

**将来、相手の king が動く面を作れる**ようにデータ構造を用意しておく。

## 9. 難易度の測り方 ―― この設計の要

**難易度は、人が推測せず、機械が測る。** 使うのは「許容度」1つだけ。

> **許容度**（ある局面） = その局面の合法手のうち、**まだ制限内に勝てる手**の割合

後ろ向きの到達可能性解析で厳密に計算できる。**評価関数もヒューリスティックも使わない。**

### 平均許容度の定義（これを固定する）

1. 制限 `T* + S` まで前向きに全局面を展開する
2. 後ろ向きに「まだ勝てる局面」を塗る
3. **ラウンド `t` の許容度** = そのラウンドの**生きている局面すべて**について、各局面の許容度を単純平均した値
4. **平均許容度** = 3 を全ラウンドで単純平均した値

局面の訪問確率で重みを付けない。到達可能な全局面を等しく数える。

### ターン制限がそのまま難易度つまみになる

制限を `T* + S` とすると、S を1増やすごとに平均許容度が**約7ポイント**上がる（測定値）。

| S | 平均許容度 | 難易度 | ★の刻み |
|---|---|---|---|
| 4 | 55%前後 | チュートリアル | ★3 / ★2 / ★1 |
| 3 | 48% | やさしい | ★3 / ★2 / ★1 |
| 2 | 42% | ふつう | ★3 / ★2 / ★1 |
| 1 | 35% | むずかしい | **★2 が★3と同条件になり消える** |
| 0 | 24% | 最難関 | **3条件が同一。クリア＝必ず★3** |

`S = 1` と `S = 0` は難易度としては使えるが、**★が3段階で機能しない**（§10）。
使うなら承知の上で使う。★の刻みは数値調整の対象である（§20）。

**序盤はやさしくてよい。** クリアできる快感を先に味わってもらい、
よく考えないと解けない面は徐々に出す。S がその順番を決める。

### 「全体の成功率」と「1ターンの許容度」を混同しないこと

経路全体の成功率は、1ターンの許容度の**掛け算**になる。
許容度40%・13ラウンドなら `0.40^13 ≈ 0.001%`。
経路全体で5〜10%にするには1ターンあたり 82% が必要で、それはもうパズルではない。

**狙う対象は1ターンあたりの許容度**である。
「1手ずつは寛容だが、通すのは難しい」という形が、分岐の多いこのゲームに合っている。

### 山場

**そのラウンドの許容度が、前のラウンドから 15 ポイント以上下がったラウンド**を山場と呼ぶ。
チュートリアル的な面なら山場ゼロ、難しい面なら2〜3箇所という設計をする。

### 同時駒数

**最適解をなぞったとき、各ラウンドの終わりに盤上にいる自分の駒の数（king を含む）を、
`T*` ラウンドで平均した値。** §21 の測定で使っている指標である。

高いほど複数の駒を並行して運用していることを意味する。
1ノード1駒の渋滞が効いているかの目安になる。

### 使えなかった指標（記録として残す）

| 試したもの | なぜ駄目か |
|---|---|
| ランダムプレイのクリア率 | どんなに易しい面でも 0.00%。10兆通りの中に勝ち筋が20本では目盛りにならない |
| 先読みプレイヤーの階段（1〜4手先） | **深く読むほど弱くなる逆転**が出た。評価関数が悪いと深い探索がその間違いを忠実に最適化する |
| 勝ち筋の本数 | 順序違いを別物として数えるので過大。`T*+2` で数千本になる |

## 10. 勝敗と★

| | 条件 |
|---|---|
| **勝利** | 相手の king を倒す（戦闘に勝つ、または相打ち） |
| **敗北** | 自分の king を失う |
| **敗北** | `T* + S` 回行動しても勝てない |

| ★ | 条件 |
|---|---|
| ★★★ | `T*` ちょうど |
| ★★ | `T* + ⌊S/2⌋` 以内 |
| ★ | `T* + S` 以内（＝クリア） |

**条件を満たした中で最上位の★を与える。**
`S = 1` では★★の条件が★★★と同じになるので、★の刻みは数値調整の対象とする（§20）。

### undo

**1手戻すボタンを置く。制限なし。★にも影響しない。**
undo で試行錯誤できるのは他のパズルゲームと同じである。

**そのかわり、詰みを通知しない。**
プレイヤーが「もう勝てない」と分かるのは、ターンを使い切ったときだけである。

これは意図的な設計である。詰んだ瞬間に知らせると、
**「そこまでの手を覚える → まだ試していない手を試す」の繰り返しで、考えずに解けてしまう。**
どこで失敗したか分からないからこそ、盤面を読む必要が生まれる。

engine は許容度の解析で「どの局面が生きているか」を知っているが、**その情報をプレイヤーに出さない。**

## 13. 要素を出す順（章構成）

**リリースは全要素入りである。** 以下は「どの章で何を初めて登場させるか」であって、
リリースの段階ではない。**最初に全部を投下すると混乱するので、章ごとに1つずつ増やす。**

**レベル設計の鉄則**: king で相手の king を倒すには、§5 の条件4 により**常に1レベル上が要る**。
序盤の章はこれを満たすように組む。満たさないと**1面目から解けない。**

| 章 | 初めて出る要素 | 盤面の条件 |
|---|---|---|
| 1 | 移動。相手の king を倒す | 壁なし、攻撃なし、駒は king のみ。**自 king Lv2 / 相手 king Lv1** |
| 2 | **自分のターン終了時に施設に乗っていると効果を受ける** | 自 king Lv1、**訓練場 Lv2、相手 king Lv1**。乗って待てば Lv2 になり届く |
| 3 | **足踏みで施設のレベルを上げる** | **相手 king Lv2、訓練場 Lv2**。育てても Lv2 止まりで届かない → 訓練場を Lv3 に上げる |
| 4 | 壁。壊すと駒が消える | 壁 Lv2、相手 king Lv2、訓練場 Lv3、**初期2体**。壁役と王役で訓練場を取り合う |
| 5 | 小屋で駒を買う | 小屋を置き、初期配置を king のみに戻す |
| 6 | 採掘場で稼ぐ | 初期コインを絞る |
| 7 | **削ってから倒す**（§5②） | 相手 king Lv4、訓練場 Lv2。1体では届かないので複数体でぶつける |
| 8 | 定期攻撃（弓・大砲）。king を失うと負ける | 攻撃1つ。king の通り道に置く |
| 9 | 足止め・封鎖 | 攻撃2つ |
| 10 | 敵陣の施設 | 壁の向こうに高レベルの訓練場（相手 king Lv3 以上、奥 Lv3 以上） |
| 11 | 追尾攻撃 | `{snare, duration:2, rule:'king', period:4}` |
| 12 | 敵の駒（占拠型 → 進軍型）、戦闘 | 敵の小屋を置く |
| 13 | 馬小屋と速度 | |

**1章につき1つだけ増やす。** 特に次の3組は別の概念なので、まとめない。

- 章2「乗って自分のターンを終えると効果を受ける」／ 章3「足踏みで施設自体のレベルを上げる」
- 章5「コインを使う」／ 章6「コインを稼ぐ」
- 章2〜6「育てて1体で倒す」／ 章7「安い駒を並べて削ってから倒す」

章3 は**「育てても届かない。だから施設そのものを強くする」**という気づきの形になっている。
足踏みを教える理由が盤面から出てくるので、説明が要らない。

章7 で2つ目の勝ち方が出るまで、プレイヤーは「1体を育てる」しか知らない。
そこで初めて「**数で削る**」を見せると、以後の面が一気に広がる。

**専用のチュートリアル面は作らない。** 章の最初の面がその役割を兼ねる。
ルールの確認は**「あそびかた」（プレイ画面の右上の ?）**でいつでも読めるようにする（§14）。

## 14. UI

`shared-ui/` の規約に従う。

- **プレイ画面の1行目は、戻る・タイトル・設定・? の4つだけ**
- コイン・残りターン・敵の攻撃カウントは**2行目（`.status-bar`）**へ
- 2行目は中身が空でも高さを取る
- ホームに「あそびかた」「きろくをけす」を置かない

### 操作

- **ドラッグに統一。** 隣へドラッグ＝移動、その場へドラッグ＝足踏み／生成
- **確認ダイアログを出さない**
- **掴んだ瞬間に、行ける先をすべてハイライトする。** 確認を出さない以上、これが誤操作の防波堤
- 盤外で離す／掴んだ場所に戻すとキャンセル
- 掴める要素には `touch-action: none` を付ける
- ドラッグとタップは 7px 程度の閾値で分ける
- **盤面は操作で1px も動かない。** 駒は絶対配置でノードに重ねる
- アニメーション中は入力を受け付けない
- 効果音は WebAudio で合成する。音声ファイルを持たない
- `navigator.vibrate` で触覚を返す

### undo

**1手戻すボタン。制限なし。★にも影響しない。**
**詰みは通知しない**（§10）。

### 敵の行動を全部見せる

**次に何が起きるかを隠さない。** 決定的であることが唯一の売りなので、
読めるはずの情報が読めない状態を作らない。

- 攻撃ごとに「あと何ターン／対象ノード／種類」を常時表示。攻撃が複数あるなら全部出す
- 追尾攻撃は**いま誰が狙われているか**を盤上で示す
- 敵駒の次の移動先を矢印で示す

**ただし「もう勝てない」ことは出さない。** 敵の行動は見せるが、詰みは見せない。

### あそびかた（?）

専用のチュートリアル面を作らない以上、ここが唯一のルール参照先になる。
**§2 の5つのルール、施設4種、攻撃4種、戦闘、勝敗条件**を、
1画面1トピックで読めるようにする。盤面の図を添える。

### レベルの見せ方

駒・施設・壁・king のレベルは**同じ表記**で出す。同じ規則で比べるものだから。
訓練場に居る駒は、**あと何ターンで上限に達するか**が見えること。
**駒のレベルは数字だけでなく姿でも変える**（実装時に詰める）。

### king の見せ方

**king は一目で他の駒と区別できること。** 自分の king と相手の king も明確に分ける。
敵の攻撃対象ノードは、自分の king が居るときだけ警告の強さを変える。

### アート

生成AIで**1枚のシートにまとめて**描き、スクリプトで切り出す（`scripts/slice-sprites.mjs`）。
駒ごとに別々に生成すると絵柄・線幅・光源・彩度が揃わず必ず破綻する。
盤面の色は共通化しない。寄せるときは相対輝度で14%以上離す。

## 15. 保存と進行

| 項目 | 内容 |
|---|---|
| ステージごとの記録 | 最高★、最短クリアターン、クリア済みか |
| 解放状況 | どの章まで開いているか |
| 中断した盤面 | 状態と、undo のための履歴 |
| 設定 | 音・触覚のオン／オフ |

★とクリアターンは**ベストのみ保持**。中断した盤面は**毎ターン保存**し、クリアまたは敗北で消す。

**保存する前に容量を実測する**（CLAUDE.md）。特に undo 履歴は1ラウンドぶんの状態を積むので、
`T*+S` 回ぶん × 盤面の大きさになる。実測して、必要なら**差分だけ持つ**か**直近 N 手に限る**。

「きろくをけす」は**開発者メニュー（右下の「テスト用」）の中**に置く（CLAUDE.md）。

章ごとに一覧を出す。**章の中の面は最初から全部開いている**（詰まったら次に進めるように）。
**次の章は、前の章を N 面クリアで開く**（N は章のサイズの 7 割程度）。

### ステージ定義に持つもの

- ノードとエッジ、各ノードの種類・施設・初期レベル・壁のレベル・座標
- 初期の駒（自分の king、相手の king、その他）
- 初期コイン、`S`（ターン制限の余裕）
- 攻撃の配列、敵駒の配列
- 章と並び順、表示名
- **生成器が焼き込む値**: `T*`、平均許容度、山場のラウンド

`T*` は作問時にソルバーが求め、ステージ定義に焼き込む。
**アプリ実行時にソルバーを走らせない**（1〜3分のパズルの開始前に探索を待たせることになる）。
許容度の解析も作問ツール（Node 側）だけで走らせる。

型の詳細は実装時に詰める。**駒には位置と別に同一性を持たせること**
（足止めの追跡、移動アニメーション、追尾攻撃の「いま誰が狙われているか」の表示に要る）。

出荷版は **IDA\* ＋ 置換表**。探索は Web Worker に出し、同期フォールバックも用意する。

### 決定性

乱数はゲーム進行に一切使わない。
ステージ生成の乱数はレベル番号から種を作る。同じ入力から必ず同じ盤面が出る。

## 17. 作問と監査

生成器で候補を出し、ソルバーで検証し、監査ツールで落とす。採否は人が決める。
`scripts/audit-levels.mjs` を常設し、パラメータを変えたら毎回走らせる。

### 構造の検査

king が両陣営に1つずつか / `edges` が `nodes` に閉じているか / 攻撃の対象が実在ノードか /
対象と規則が排他か / 初期駒の位置が重複していないか / `T*` が焼き込まれているか。

### 品質の監査

| 落とす条件 | 理由 |
|---|---|
| ソルバーが解けない | 詰み |
| **小屋が無く、初期駒が king のみで、かつ駒を失う要素（攻撃または壁）がある** | king 1駒で戦う羽目になる。測定で確認済み |
| **強制スキップが最適解の周辺に現れる**（§2④） | 何もできないラウンドが発生している |
| 平均許容度が `S` に対応する帯から外れている | 難易度が意図とずれている |
| 敵の行動が最適解に一度も影響しない | 時計が飾りになっている |
| 1ノード1駒の制約が一度も効かない | 盤面が広すぎる。ノードを減らす |
| 敵陣の施設が置いてあるのに一度も使われない | §3 の条件（相手の king Lv3以上・敵陣訓練場 Lv3以上）を満たしていない |

**小屋の条件は3つの積である。** 章1〜3 のように駒を失う要素が無い面では小屋は要らないし、
章4 のように初期配置を2体にして小屋を置かない面もあってよい。
落とすのは**「補充できず、初期駒も king だけで、しかも失う」**が揃った面だけである。

**king の稼働は条件にしない。上限も下限も置かない。**
king が働く面も、座ったままの面も、king が最後の一撃を入れる面もあってよい（§2⑤）。

**「3施設すべてを使う」も条件にしない。** 速攻面では訓練場を使わないのが正解であり、それでよい。

### 構造の検査に加えるもの

相手の king が動かない設定になっているか / 敵駒を生成する面に敵の小屋があるか /
自分の小屋と相手の小屋が所有者つきで区別されているか。

## 18. スコープ外 ―― 将来の別ゲーム

**思考する CPU はこのゲームには入れない。**

決まった規則で動く敵なら、どれだけ複雑でも盤面から次の手が一意に決まるので問題ない。
一方その場で探索して最善手を選ぶと、`T*` が min-max になって意味が変わり、
許容度が相手の応手に依存して計算できなくなる。
**★の自動決定も、難易度の機械測定も、監査ツールも、全部そこに乗っているので一緒に無効になる。**

ただし本作のルールは**ほぼ対称**である。

**対称な部分**

- 採掘場・訓練場・馬小屋に所有者がいない（§3）
- 小屋は所有者を持つが、お互いに自分の小屋を持つ（§3）
- 戦闘規則が対称（§5）
- **お互いに king を持ち、相手の king を倒したら勝ち**（§2⑤）
- ターンが交互に来る（§7）
- 施設の効果は、そのターンのプレイヤーの駒にだけ効く（§7）

**非対称な部分 ―― 対戦ゲームにするときの最大の課題**

**攻撃（弓・大砲・足止め・封鎖）は敵側しか持たない。** こちらから相手を撃つ手段はない。
ソロのパズルでは「敵は時計である」という設計そのものなので問題ないが、
対戦ゲームにするなら**両者が攻撃手段を持つ形に作り替える必要がある。**

コインを攻撃に払う、施設として「弓塔」を置く、など方向はいくつかあるが、
**本作では扱わない。** 切り出すときに設計する。

**それ以外は盤面条件を揃えればそのまま対戦ゲームになる。**
このパズルを作り切ったあと、仕様を引き継いで別タイトルとして切り出す。
思考する CPU との対戦 / PvP / デッキ編成。

## 19. 曖昧さの裁定一覧

| 論点 | 裁定 |
|---|---|
| ターンの構造 | **自分のターン → 相手のターン の交互制。** 1組が1ラウンド。`T*` は自分の行動回数 |
| 施設が発動するタイミング | **各ターンの終わり。そのターンのプレイヤーの駒にだけ**発動する |
| 攻撃の発火 | 残りカウントが**相手のターン開始時に1減り、0 で発火**。発火後は `period` に戻る |
| 勝敗判定の順序 | **勝利 > 敗北 > 時間切れ。** 勝利は自分のターンで即確定し以降を実行しない |
| 行動できる回数 | **`T* + S` 回** |
| 勝利条件 | **相手の king を倒す。** 敵城は相手の king の初期位置という呼び名にすぎない |
| 相手の king と同レベルの駒をぶつける | **相打ち。相手の king が消えるので勝ち** |
| 相手の king より弱い駒をぶつける | **自駒は消えるが、相手の king はそのぶんレベルが下がる**（§5②の削り） |
| 壁は禁じ、戦闘は許す理由 | 壁のレベル不足は完全な無駄、戦闘の敗北は相手を削れる有効手だから |
| 足踏みで効果が無いとき | **何も起きない。** 小屋の上・最大レベル・コイン不足・道の上すべて同じ |
| 施設が効くタイミング | **自分のターン終了時にそこに居ること。** 通過では効かない |
| 足止めされた駒 | **そもそも選べない。** 移動も足踏みも不可。**その駒が居る施設の効果も受けない** |
| 攻撃が当たる対象 | **プレイヤーの駒だけ。** 対象ノードに敵駒が居ても何も起きない |
| 同時駒数の定義 | 最適解をなぞり、各ラウンド終了時の自駒数（king を含む）を `T*` で平均した値 |
| 足踏みはいつ選べるか | **選べる駒（足止めされていない自分の駒）があれば常に** |
| 何もできないとき | **1ラウンド強制スキップ**（特殊演出）。敗北にはしない。監査で落とす |
| 小屋の所有者 | **小屋だけは所有者を持つ。** 自分の小屋でしか生成できない。相手の小屋は塞げる |
| 敵駒の生成元 | **敵の小屋。** 空いているときだけ生成される |
| king 同士の相打ち | **敗北**（自分の king を失うため）。ただし §5 条件4 により自分からは選べない |
| 相手の king | **当面すべての面で動かさない** |
| 足踏みで上げたレベルは同ターンの発動に乗るか | **乗る** |
| 足踏みの支払いに同ターンの採掘収入を使えるか | **使えない**（支払いが先） |
| 封鎖されたノード | **入れない。既に居る駒は出られる。** 施設は発動し、足踏みもできる |
| 持続の数え方 | 付与ラウンドには減算しない。`duration: N` でちょうど N ラウンド |
| 戦闘で同レベル | **相打ち。両方消え、ノードは空になる** |
| king を同レベル以上の敵駒にぶつける | **移動先として選べない**（自滅操作を作らない） |
| 進軍型の経路の同率 | 次に進むノードIDの昇順 |
| 敵駒とコイン | 敵駒は足踏みせず、採掘場に居てもコインは誰にも入らない |
| 壊れた壁ノード | 以後は道と同じ |
| 平均許容度の分母 | 到達可能な生きている全局面を等しく数える |
| 山場の定義 | 前のラウンドから許容度が15ポイント以上下がったラウンド |
| undo | 自由。★に影響しない。**そのかわり詰みを通知しない** |
